# CRUD PHP MySQL

Aplikasi data mahasiswa sederhana (PHP + MySQL) untuk praktikum Pengembangan Aplikasi Web.

Fitur: login admin (session), tampil, tambah, edit, dan hapus data mahasiswa.

## Cara menjalankan

1. Letakkan folder project di `htdocs` (XAMPP), lalu Start Apache dan MySQL.
2. Buka `http://localhost/<nama-folder>/generate.php` satu kali untuk membuat database `my_campus`.
3. Buka `http://localhost/<nama-folder>/` lalu login.

Login: username `admin`, password `adminmahasiswa`.
